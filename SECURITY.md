# Security

## Reporting a Vulnerability

Please do not publish security vulnerabilities, credentials, API keys, or private information in a public issue.

For sensitive reports, contact the repository owner through the contact information available on the GitHub profile.

## Secrets
Never commit:
- API keys
- passwords
- access tokens
- private certificates
- personal authentication data
- private user datasets

If a credential is accidentally committed, revoke or rotate it immediately and remove it from the repository history as appropriate.

## Personal Data
Do not commit identifiable medical, biometric, voice, face, or sign-language datasets without appropriate permission and privacy safeguards.
