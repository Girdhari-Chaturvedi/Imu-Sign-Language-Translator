# Gesture Logic

Prototype labels included by the firmware:
YES, NO, HELP, THANK YOU, HELLO, WATER, FOOD, BYE, COME HERE, GO, STOP, WAIT, GOOD MORNING, GOOD NIGHT, EMERGENCY, I NEED HELP, PLEASE, SORRY, OK.

These are experimental threshold-based mappings, not complete sign-language recognition.

For a stronger recognizer: keep sensor placement consistent, calibrate, record labeled five-sensor time series, train a classifier, validate on unseen sessions, and add confidence/neutral-state handling.
