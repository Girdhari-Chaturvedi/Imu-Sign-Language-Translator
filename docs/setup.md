# Setup

1. Install Arduino IDE.
2. Select Arduino UNO and the correct COM port.
3. Open firmware/arduino_5x_mpu6050/arduino_5x_mpu6050.ino.
4. Upload.
5. Open Serial Monitor at 9600 baud.
6. Keep all sensors still during startup calibration.
7. Confirm S1-S5 are detected.
8. Pair HC-05 with a Bluetooth serial terminal.
9. Verify DATA and SIGN messages.
10. For Python voice, install software/desktop_usb_voice/requirements.txt and close Serial Monitor before connecting Python.
