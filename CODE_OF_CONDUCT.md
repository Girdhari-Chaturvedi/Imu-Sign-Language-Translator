# Code of Conduct

## Our Standard

We aim to keep this project technical, constructive, inclusive, and respectful.

Examples of expected behavior:
- Be respectful and professional.
- Focus criticism on code, designs, data, and technical decisions.
- Share reproducible evidence when reporting problems.
- Welcome questions from beginners and experienced contributors.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, and deliberate disruption.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when behavior violates this standard.

For serious or sensitive concerns, contact the repository owner privately through the GitHub profile.
